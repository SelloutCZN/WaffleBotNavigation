This repository contains the full ROS2 package prepared to control a TurtleBot3 Waffle to navigate an arena with obstacles (https://youtu.be/aWCGr5v9SjY). 

This work was completed as part of project work in the ELE434 module at the University of Sheffield (2025-26). 

---
Information on the TurtleBot3 Waffle can be found here: https://www.turtlebot.com/turtlebot3/
